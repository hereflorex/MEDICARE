THE PROJECT

A hospital workflow, rebuilt for clarity.

The goal is simple: make common healthcare-management tasks easier to understand and quicker to reach.

Full-stack foundation

Flask routes, SQLAlchemy models, PostgreSQL-ready configuration and role-aware sessions form the application core.

Interface first

Responsive layouts, clear hierarchy, focused actions, useful states and subtle motion keep the UI practical instead of noisy.

Security minded

Authentication and authorization are enforced server-side with protected sessions, password hashing and CSRF-aware state changes.
